# Jedidiah Chege - Portfolio v1.0

Welcome to the first version of my personal portfolio website!

## About This Project
This is an immersive web portfolio built to showcase my journey bridging the gap between **hardware engineering** (Mechatronics) and **digital experiences** (Mobile & Web Development). 

It features a premium, dark-themed glassmorphism layout layered over a cursor-tracking 3D Spline scene.

### Tech Stack
- **Build Tool:** Vite
- **Logic:** Vanilla JavaScript
- **Styling:** Tailwind CSS (with custom neon glows and gradients)
- **3D Engine:** Spline (`@splinetool/viewer`)
- **Deployment:** Netlify

## Future Improvements 🚀
This repository represents the foundational build (v1.0) of my portfolio. I plan to continuously iterate and upgrade the site as my skills grow. Planned future improvements include:
- Expanding the "Selected Works" to include dedicated, detailed case study pages.
- Adding interactive 3D CAD renders for my Mechatronics/hardware projects (like the Micromouse).
- Enhancing mobile responsiveness and adding scroll-triggered micro-animations.
- Integrating a custom domain and improving SEO.

## Getting Started
To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/printf-Jed/Jed-s-Portfolio-Website.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
